# 1309 Queens Bush Road Property Website

## Goal

Create a premium single-property website that helps sell 1309 Queens Bush Road through original editorial copy, verified property facts, and a curated selection of the supplied professional photography.

## Audience and Positioning

The primary audience is an affluent buyer seeking a distinctive, substantial home with privacy, architectural character, generous entertaining space, and strong indoor-outdoor living. The tone will be warm, confident, and restrained. Copy will be written from scratch and will not reproduce the Lambert Group listing language.

## Page Structure

The site will be one responsive page containing:

1. A full-bleed photographic hero with the address, an original positioning line, and the primary inquiry action.
2. A concise verified-facts strip.
3. Image-led editorial sections covering the setting, exterior architecture and grounds, interior living spaces, kitchen, primary suite, and distinctive amenities.
4. A curated gallery selected from the 215 supplied photographs.
5. A factual feature summary.
6. An optional link to the approved iGuide tour and floor plan.
7. A repeated contact or private-viewing action.

## Content Rules

- Use only property facts confirmed by the owner or verified against the supplied listing.
- Do not repeat the source listing's superlatives, anecdotes, lifestyle claims, business-use suggestions, condition assurances, or maintenance claims.
- Do not invent testimonials, neighbourhood claims, lot dimensions, pricing, upgrades, or legal details.
- Price may be omitted until confirmed.
- Contact details, brokerage disclosures, lot size, listing status, and the final CTA remain content inputs that can be inserted without changing the design.

## Visual Direction

Before implementation, present exactly three comparable visual directions using the Sites design picker. All directions should feel premium and editorial while differing meaningfully in typography, palette, image treatment, and composition. The selected direction becomes the implementation source of truth.

The site should favour large photography, restrained typography, generous spacing, and subtle native motion. Avoid carousels, decorative illustration, model-generated property imagery, excessive animation, and added dependencies unless the existing Sites starter already provides something essential.

## Photography

Preserve all original files unchanged. Select a representative set across drone, exterior, and interior categories; do not publish all 215 images. Create web-sized derivatives with responsive crops and modern formats, lazy-load below-fold images, and provide meaningful alt text.

## Accessibility and Responsive Behaviour

The site must work across phone, tablet, and desktop widths. Text must remain readable over imagery, controls must have visible keyboard focus and adequate touch targets, colour contrast must be sufficient, and motion must respect reduced-motion preferences.

## Metadata and Sharing

Use address-led page metadata and an original description. Create one site-specific social preview only after the final visual direction and copy are stable. Do not ship starter metadata or a generic social image.

## Verification

Before handoff:

- Recheck every displayed property fact against the approved source information.
- Verify representative phone, tablet, and desktop layouts.
- Check image crops, loading behaviour, and overall page weight.
- Test keyboard navigation, visible focus, contrast, alt text, and reduced motion.
- Test all links and inquiry actions.
- Run the production build successfully.
- Review the finished page visually in a browser.

Publishing is a separate approval boundary. The initial delivery is a reviewed preview unless the owner explicitly approves publication.

## Acceptance Criteria

- The site presents 1309 Queens Bush Road as a distinctive premium property without borrowing the source listing's prose.
- The strongest supplied photographs drive the experience while the originals remain untouched.
- Every published factual claim is verified.
- The experience is responsive, accessible, performant, and visually coherent.
- The inquiry path is obvious and uses owner-approved contact details.
- No site is published without explicit approval.
